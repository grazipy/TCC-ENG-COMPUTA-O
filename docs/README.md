# Documentação do projeto

Estrutura base para os artefatos acadêmicos e técnicos do TCC:

- `tcc/`: texto base, capítulos e anexos.
- `diagramas/`: diagramas de arquitetura, rede, sequência e banco.
- `apresentacao/`: slides e roteiro da banca.
- `requisitos/`: requisitos funcionais e não funcionais.
- `api/`: contrato de endpoints, exemplos e versionamento.
